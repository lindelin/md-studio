# MD Studio 中文使用手册

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [首页](../../README.zh-CN.md)

适用于 Windows 版 MD Studio 1.0.0。[下载安装包](https://github.com/lindelin/md-studio/releases/latest)。

## 1. 安装与连接

运行 `MD-Studio-Setup-1.0.0.exe`，选择安装位置，然后启动 MD Studio。不需要下载源码或安装 Node.js。目标系统为 Windows 10/11 64 位。当前安装包未签名，可用发布页的 `SHA256SUMS.txt` 核对下载文件。

插入可写 MD，确保碟机稳定供电并连接 USB。在**设备**页面选择对应的 NetMD／Hi-MD 连接方式，再连接设备。插入多台兼容设备时，从列表选一台；当前版本一次只控制一台碟机。Hi-MD 可用操作随连接方式和设备而异。

NetMD 缺驱动时，打开**设置 → 设备驱动 → 检测驱动**，按提示启动内置 Zadig。核对碟机名称与 USB ID，再选择 WinUSB。驱动安装需要管理员权限；不要替换其他设备或 Hi-MD 存储接口的驱动。此安装包不要求另外下载 Zadig。

设置中可选择简体中文、日本語、English 或跟随系统，以及浅色／深色／系统主题。首次安装默认跟随系统语言。

## 2. 导入与编排

在设备页面点击选择音频文件，添加本地音乐。不需要曲库服务或文件夹索引。应用会读取可用标签；WAV 也可能有标签，缺失时需参考文件名。导入后检查内容，不要默认原标签一定正确。

在录制计划中调整曲序，选择设备支持的模式。普通 MD 使用 SP、LP2、LP4、MONO 等名称；Hi-MD 可提供其他格式。开始前检查容量预览。同一张 MD 上的曲目可以有不同录制模式，曲目行显示的是该曲的实际模式。

标准录制流程的音频解码与编码在本机完成，无需服务器转码或另装标准编码器。不可用的可选编码器不影响内置流程。

## 3. 曲名、艺术家、专辑和分组

| 字段 | 普通 MD／NetMD | Hi-MD |
| --- | --- | --- |
| 普通标题 | 使用兼容半角字符；本工具默认把日文整理为半角片假名读音 | 使用设备支持的原始文字 |
| 全角标题 | 全角英文，或包含汉字的原始日文；是否显示取决于播放设备 | 使用该设备提供的字段 |
| 艺术家／专辑 | 用于整理的来源信息，不是独立碟上字段 | 支持时可分别保存 |
| 文件夹（Group） | 给连续曲目命名的分组，常按专辑建立 | 以设备提供的分组能力为准 |

普通 MD 的碟名、组名也采用半角／全角整理策略。全角英文是本工具的排版策略，不保证每个播放器都支持显示。汉字转换宽度不能得到读音，人名和特殊曲名应让 AI 查证后再转半角片假名。

选中曲目后在右侧编辑并应用标签。普通 MD 可用碟名或组名表达专辑，不能把艺术家、专辑当成独立字段已写入。保留 live、remix、instrumental 等版本信息。这里的编辑不会改写源音频标签。

在碟片列表选择连续且未归组的曲目，点击**新建文件夹（Group）**。点击组名可选中并改名；取消分组不会删除音频。调整成员时先取消分组、调整顺序，再重新分组。组名不要包含 `//`。遵守标题容量检查，缩写或截断前先核对。

## 4. 让 AI 制作 MD

1. 打开**AI 制作**并开启 MCP。开启一次后会随应用启动。
2. 把完整地址填入支持**本地 HTTP MCP**的 AI 客户端。地址含访问密钥，重启、关闭再开启后保持不变；请勿分享。清除应用数据或换电脑可能需要重新配置。
3. 导出 **MD 标签整理 Skill**，按客户端支持的方式安装。Skill 提供标题、读音、分组规则，不是 AI 模型。
4. 让 AI 读取当前设备和碟片状态、导入音乐并生成计划。检查曲序、半角／全角标题、分组、模式、容量，再授权录制。
5. 要求 AI 等待实际任务完成并读回碟片。预览通过或命令已接收不代表录制成功。

示例：

> 把 C:/Music/Album 按曲序整理，用 LP2 制作 MD。全角标题保留原始日文，普通标题核实读音后转半角片假名。按专辑分组。不确定的读音和容量先给我看，确认后再写盘。

纯云端客户端无法直接访问本机 localhost。请使用兼容的本地客户端，不需要公网端口转发。AI 服务、账号与费用由你使用的客户端决定。音频转换和 USB 传输在本机；对话和标签信息可能按 AI 客户端的隐私设置发送到它的服务商。

## 5. 不用 MCP，直接使用 CLI

保持 MD Studio 运行。启动器位于 `%APPDATA%\MD Studio\mdstudio.cmd`，也可以在 AI 制作页面复制路径。PowerShell 示例：

```powershell
$md = "$env:APPDATA\MD Studio\mdstudio.cmd"
& $md --help
& $md workspace
& $md add "C:\Music\Album\01.flac" "C:\Music\Album\02.flac"
& $md preview LP2
# 以下命令会将当前队列实际写入碟片：
& $md write LP2
& $md tasks
```

`preview` 不写盘；`write` 会等待任务结果。CLI 与界面共用当前队列和设备，不是另开一个会话。桌面 CLI 无需打开 MCP。结构化命令见[自动化参考](../AUTOMATION.md)。

## 6. 录制、后台运行和初始化

录制灯闪烁时保持供电与 USB 连接。**当前曲目完成后结束批次**只阻止后续曲目开始，不会立即停止正在录制的曲目。等待完成后再取碟。

关闭窗口后，应用留在系统托盘，录制、MCP 和 CLI 继续工作。双击托盘图标恢复窗口，选择**退出**才结束应用。后台运行不是 Windows 服务，应用仍需运行，电脑不能休眠。

碟片维护提供擦除／初始化，以及设备支持时的 Hi-MD 格式化。这些操作会删除数据。仔细阅读确认信息，按原样输入确认短语；语言切换不会改变必须输入的确认令牌。

## 7. 常见问题

- **USB 接口无法占用／找不到碟机：** 关闭其他 MD 应用和标签页，检查电源，重插 USB 并检测驱动；多设备时选对碟机。
- **录制慢：** 转码和传输速度由模式及硬件决定。查看任务进度，不要拔出仍在写入的设备。
- **掉电／断线：** 重新连接、刷新碟片，核对已完成曲目，只重试剩余部分。
- **AI 连不上：** 确认应用运行、MCP 已开启、客户端支持本地 HTTP MCP；重新复制完整地址但不要公开。端口占用也会阻止服务启动。
- **标题显示异常：** 检查半角／全角字段和播放器字符能力；AI 整理的读音也需要审阅。
- **反馈：** 在 [Issues](https://github.com/lindelin/md-studio/issues) 提供版本、Windows 版本、机型、模式、复现步骤和脱敏错误。不要附带 MCP 地址、密钥或私人音乐路径。

实机验证包含 Sony MZ-N920。其他机型沿用设备库支持，但仍可能需要进一步测试。干净系统安装卸载及更多 Hi-MD 机型还需扩大验证范围。
