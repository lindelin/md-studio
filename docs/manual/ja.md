# MD Studio 日本語マニュアル

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [ホーム](../../README.ja.md)

Windows 版 MD Studio 1.0.0 用。[インストーラーを入手](https://github.com/lindelin/md-studio/releases/latest)。

## 1. インストールと接続

`MD-Studio-Setup-1.0.0.exe` を実行し、インストール先を選んで MD Studio を起動します。ソースコードや Node.js は不要です。対象は Windows 10/11（64 ビット）です。現在のインストーラーは未署名です。公開されている `SHA256SUMS.txt` とダウンロードファイルを照合できます。

書き込み可能な MD を入れ、安定した電源を確保して USB を接続します。**デバイス**ページで対応する NetMD／Hi-MD 接続方式を選んで接続してください。対応機器を複数接続した場合は一覧から選択します。このバージョンで同時に操作できるレコーダーは 1 台です。Hi-MD の操作範囲は接続方式と機器によって異なります。

NetMD のドライバーが必要な場合は、**設定 → デバイスドライバー → ドライバーを確認**へ進み、案内に従って同梱の Zadig を開きます。機器名と USB ID を確認してから WinUSB を選択してください。管理者権限が必要です。無関係な機器や Hi-MD ストレージのドライバーは置き換えないでください。別途 Zadig をダウンロードする必要はありません。

設定で日本語・英語・簡体字中国語・システム言語、およびライト／ダーク／システムテーマを選択できます。新規インストール時はシステム言語に従います。

## 2. 音楽の追加と録音プラン

デバイスページの音声ファイル選択ボタンから音楽を追加します。音楽ライブラリー用サーバーやフォルダーの索引設定は不要です。タグがあれば読み込みます。WAV にもタグがある場合があり、なければファイル名などを参考にします。取り込み後に内容を確認してください。

録音プランで曲順を整え、対応するモードを選びます。通常の MD では SP・LP2・LP4・MONO など、Hi-MD では別の形式も利用できます。開始前に容量の見積もりを確認します。同じ MD に異なるモードの曲が入ることもあり、曲の行には実際の録音モードが表示されます。

標準の録音処理にはローカルでのデコードとエンコードが含まれます。サーバー変換や標準エンコーダーの追加インストールは不要です。利用できないオプションのエンコーダーを用意しなくても、内蔵の処理を利用できます。

## 3. タイトル・アーティスト・アルバム・グループ

| 項目 | 通常の MD／NetMD | Hi-MD |
| --- | --- | --- |
| 通常タイトル | 対応する半角文字。日本語は半角カタカナの読み方を使うのが本アプリの既定方針 | 対応文字で元の曲名を保持 |
| 全角タイトル | 全角英字、または漢字を含む元の日本語。表示可否は再生機器に依存 | 機器が提供する項目に従う |
| アーティスト／アルバム | 整理用の元情報であり、独立したディスク項目ではない | 対応していれば個別に保存 |
| グループ | 連続した曲の範囲に名前を付ける。アルバム単位など | 機器が提供する機能に従う |

通常の MD では、ディスク名とグループ名も半角／全角の方針に沿って整理します。英字を全角にするのは本アプリの整形方針で、すべてのプレーヤーでの表示を保証するものではありません。漢字の文字幅を変えても読み方にはなりません。人名や特殊な曲名は AI に読み方を確認させてください。

曲を選んで右側で編集し、適用します。NetMD ではアルバム名をディスク名やグループ名に使えますが、独立したアルバム・アーティスト欄として保存したとは扱いません。live、remix、instrumental などの版情報は残しましょう。この編集で元の音声ファイルのタグは変更されません。

ディスク内の連続した未グループ曲を選び、**新規グループ**を押します。グループ名をクリックして選択・改名できます。グループ解除で音楽は消えません。メンバーを変える場合は解除して曲順を調整し、再作成します。グループ名に `//` は使わないでください。タイトル容量の確認に従い、勝手に短縮せず内容を見直します。

## 4. AI と MD を作る

1. **AI 制作**で MCP を有効にします。一度有効にすると、次回からアプリとともに起動します。
2. **ローカル HTTP MCP**に対応する AI クライアントへ URL 全体を登録します。アクセスキーを含むため共有しないでください。再起動やオン／オフで URL は変わりませんが、アプリデータの削除や PC の変更時は再設定が必要になる場合があります。
3. **MD タグ整理 Skill**をエクスポートし、クライアントの方法に従ってインストールします。Skill はタイトル・読み方・グループの規則を教えるもので、AI モデルではありません。
4. AI に現在の機器とディスクを確認させ、音楽を追加してプランを作らせます。曲順、半角／全角タイトル、グループ、モード、容量を確認してから録音を指示します。
5. タスクが実際に完了するまで待ち、ディスクを読み直すよう依頼します。プレビュー成功やコマンド受信だけでは録音完了を意味しません。

例：

> C:/Music/Album を曲順に整理して LP2 で録音したい。全角タイトルは元の日本語、通常タイトルは読み方を確認して半角カタカナに。アルバム名でグループを作って。不確かな読み方と容量を先に見せて、確認してから書き込んで。

クラウドだけで動作するクライアントから PC の localhost に直接接続することはできません。対応するローカルクライアントをご利用ください。ポートの外部公開は不要です。AI のアカウントや料金は別です。音声変換と USB 転送はローカルですが、会話やタグ情報はクライアントの設定に従って AI 提供元に送信される場合があります。

## 5. MCP を使わず CLI から操作

MD Studio を起動したまま使います。ランチャーは `%APPDATA%\MD Studio\mdstudio.cmd` に作成され、AI 制作ページからもパスをコピーできます。PowerShell の例：

```powershell
$md = "$env:APPDATA\MD Studio\mdstudio.cmd"
& $md --help
& $md workspace
& $md add "C:\Music\Album\01.flac" "C:\Music\Album\02.flac"
& $md preview LP2
# 次のコマンドは現在のキューを実際に録音します：
& $md write LP2
& $md tasks
```

`preview` は書き込みません。`write` はタスクの結果を待ちます。CLI は画面と同じキュー・接続を使い、別の機器セッションを作りません。デスクトップ CLI に MCP の有効化は不要です。構造化コマンドは[自動化リファレンス](../AUTOMATION.md)を参照してください。

## 6. 録音・バックグラウンド・初期化

録音ランプが点滅している間は電源と USB を維持します。**現在の曲が完了したらバッチを終了**は次の曲の開始を止めますが、録音中の曲を即座に停止しません。完了を待ってからディスクを取り出してください。

ウィンドウを閉じてもシステムトレイで録音・MCP・CLI が動作します。トレイアイコンをダブルクリックして再表示し、**終了**でアプリを終了します。Windows サービスではないため、アプリを動かしたまま PC をスリープさせずに使用してください。

ディスクのメンテナンスでは消去・初期化、対応機器では Hi-MD のフォーマットができます。データが削除される操作です。確認内容を読み、表示された確認語をそのまま入力してください。言語を切り替えても確認語そのものは翻訳されません。

## 7. 困ったとき

- **USB を確保できない／機器が見つからない：** 他の MD アプリやタブを閉じ、電源と USB を確認してドライバーを検出。複数機器では選択も確認します。
- **録音が遅い：** モードと機器によって変換・転送速度は異なります。タスクの進捗を確認し、書き込み中の機器は抜かないでください。
- **電源や USB が切れた：** 再接続してディスクを更新し、完了した曲を確認して残りだけ再試行します。
- **AI が接続できない：** アプリの起動、MCP の有効化、クライアントのローカル HTTP MCP 対応を確認。URL 全体を再コピーし、公開しないでください。ポート競合でも起動できなくなります。
- **文字化け：** 半角／全角欄と再生機器の文字対応を確認します。AI の読み方も必ず確認してください。
- **不具合報告：** [Issues](https://github.com/lindelin/md-studio/issues) にアプリと Windows のバージョン、機種、モード、手順、機密情報を除いたエラーを記載。MCP URL、キー、個人の音楽パスは掲載しないでください。

Sony MZ-N920 で実機確認を行っています。他の NetMD／Hi-MD 機種は機器ライブラリの対応を引き継ぎますが、追加検証が必要な場合があります。クリーン環境でのインストール・アンインストールや幅広い Hi-MD 機種の検証は、今後も拡充が必要です。
