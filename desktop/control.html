连接与驱动 / Connections

AI 接入 · MCP

开启后复制完整地址到支持本机 HTTP MCP 的 AI 客户端。地址包含访问密钥，请勿分享。关闭后地址失效；已经提交的任务仍在应用中运行。Copy the complete URL to a local HTTP MCP client. Keep it private. Turning access off does not cancel submitted tasks.

命令行 · CLI

无需开启 MCP。应用保持打开，使用下面的命令入口。MCP is not required. Keep the desktop app open.

mdstudio.cmd status
mdstudio.cmd add "C:\Music\song.wav"
mdstudio.cmd preview LP2
mdstudio.cmd write LP2

首次连接助手 / Driver setup

检测已连接的 MD 和当前驱动。正常使用的设备无需更换驱动。安装器中只选择这里列出的目标设备及 WinUSB。Check the device and USB ID in Zadig. Do not replace mass-storage or unrelated device drivers. To restore an older driver, use Windows Device Manager → device Properties → Driver → Roll Back Driver when available, or reinstall the original vendor driver.
